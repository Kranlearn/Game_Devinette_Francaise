# Jeu de devinette - L'expression française du jour

## Présentation

Ce projet est un jeu de devinette d'expressions françaises. 
Chaque jour, une nouvelle expression est cachée et l'utilisateur doit la retrouver.
Il est utile pour apprendre le français et pratiquer la programmation.

## Fonctionnalités

- ✅ Sélection de l'expression aléatoire chaque jour
- ✅ Masquage des lettres pour le challenge
- ✅ Indices pour aider à la résolution
- ✅ Vérification de la réponse
- ✅ Affichage des résultats
- ✅ Protection des fichiers sensibles

## Installation

```bash
# Cloner le dépôt
git clone https://github.com/tu-utilisateur/devinette.git

# Installer les dépendances
pip install -r requirements.txt

# Lancer le jeu
python main.py
```
